# Even Odd Group

Displays whether you're in an even or odd raid group.

## Features

- Color-coded text display: blue for even, red for odd
- Draggable frame with lockable position
- Toggleable background
- Auto-hides when not in a raid

## Commands

| Command | Description |
|---|---|
| `/eog` | Toggle visibility |
| `/eog lock` | Toggle frame lock |
| `/eog unlock` | Unlock frame |
| `/eog bg` | Toggle background |
